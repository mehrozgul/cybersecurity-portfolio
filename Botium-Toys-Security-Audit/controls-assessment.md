# Botium Toys Controls Assessment

## Assessment Objective

The purpose of this assessment is to determine whether Botium Toys currently has the required cybersecurity controls in place.

The assessment is based on the information provided in the Botium Toys scope, goals, and risk assessment report.

## Controls Checklist

| Control | Status | Reason |
|---|---|---|
| Least Privilege | ❌ No | Least privilege has not been implemented. |
| Disaster Recovery Plans | ❌ No | No disaster recovery plans are currently in place. |
| Password Policies | ✅ Yes | A password policy exists, although its requirements are weak. |
| Access Control Policies | ❌ No | Access controls for least privilege have not been implemented. |
| Account Management Policies | ❌ No | No centralized password/account management system is in place. |
| Separation of Duties | ❌ No | Separation of duties has not been implemented. |
| Firewall | ✅ Yes | The IT department has a firewall that blocks traffic based on defined security rules. |
| Intrusion Detection System (IDS) | ❌ No | The IT department has not installed an IDS. |
| Encryption | ❌ No | Encryption is not currently used for customers' credit card information. |
| Backups | ❌ No | The company does not have backups of critical data. |
| Password Management | ❌ No | There is no centralized password management system. |
| Antivirus Software | ✅ Yes | Antivirus software is installed and regularly monitored. |
| Manual Monitoring and Maintenance for Legacy Systems | ✅ Yes | Legacy systems are monitored and maintained, although there is no regular schedule. |
| Locks | ✅ Yes | The physical locations have sufficient locks. |
| Closed-Circuit Television (CCTV) | ✅ Yes | Up-to-date CCTV surveillance is in place. |
| Fire Detection and Prevention | ✅ Yes | Functioning fire detection and prevention systems are in place. |

## Key Findings

The assessment identified several important security gaps.

### Missing Controls

- Least privilege
- Access control
- Separation of duties
- Disaster recovery plans
- IDS
- Encryption
- Backups
- Centralized password management

### Existing Controls

- Firewall
- Antivirus software
- Password policy
- Legacy system monitoring
- Physical locks
- CCTV surveillance
- Fire detection and prevention

## Overall Assessment

Botium Toys has several basic security controls in place, particularly firewall protection, antivirus software, and physical security controls.

However, important controls related to access management, data protection, monitoring, backup, and recovery are missing.

These weaknesses contribute to the company's **high risk score of 8/10**.

## Conclusion

Botium Toys should prioritize implementing the missing controls, particularly least privilege, encryption, backups, disaster recovery, IDS, and stronger access and password management.

These improvements would help reduce the organization's security risk and improve its overall security posture.
