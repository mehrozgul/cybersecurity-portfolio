# Botium Toys Security Audit

## Project Overview

This project is a security audit and risk assessment of Botium Toys, a fictional retail company.

The objective is to assess the company's existing security controls, identify security weaknesses, and evaluate compliance with relevant cybersecurity best practices.

## Audit Scope

The audit covers:

- Company assets and equipment
- Internal network and systems
- Employee devices
- Data storage and retention
- Security controls
- Compliance practices

## Risk Assessment

Botium Toys currently has a high overall risk score of **8/10**.

The assessment identified several security weaknesses, including:

- Lack of least privilege
- Lack of separation of duties
- No intrusion detection system (IDS)
- No disaster recovery plan
- No backups of critical data
- Lack of encryption for sensitive data
- Weak password requirements
- No centralized password management system

## Existing Security Controls

Some controls are already in place, including:

- Firewall
- Antivirus software
- CCTV surveillance
- Physical locks
- Fire detection and prevention systems
- Data integrity and availability controls

## Compliance Assessment

The audit also evaluates Botium Toys against:

- PCI DSS
- GDPR
- SOC 1 / SOC 2

## Key Objective

The main objective of this audit is to identify security gaps and recommend improvements that can strengthen Botium Toys' overall security posture.
